# If on a winter's night

Тема для Tavo по роману Итало Кальвино «Если однажды зимней ночью путник». Её я предложил сам.

- **Фон** — зимний ночной вокзал. Часы почти на полночь, два фонаря, тёплое окно буфета, поезд со светящимися окнами, пар и туман над платформой, снег. Нарисовано скриптом.
- **Ответы персонажа** — каждый как начало нового романа. Над ним название одного из десяти начатых в книге романов: «I · If on a winter's night a traveler», «II · Outside the town of Malbork» и так далее. Вместе эти названия складываются в одну фразу. Название выбирается по самому сообщению (сколько абзацев, есть ли курсив), так что у разных сообщений разные главы. Справа свисает бордовая закладка: роман недочитан. По странице медленно падает снег.
- **Ваши сообщения** — реплики Читателя, курсивом.
- **Генерация.** Пока персонаж отвечает, над полем ввода поднимается пар паровоза и идёт снег.
- **Шрифт** Spectral / Spectral SC (SIL OFL 1.1), лицензия лежит в `assets/`.

Файл: `dist/winter-traveler.thm`. Нужен **Advanced Rendering**. Пересборка: `python3 themes/winter-traveler/build.py`.
