# The Library of Babel

Тема для Tavo по рассказу Х. Л. Борхеса «Вавилонская библиотека». Её я выбрал сам: библиотека, где есть все возможные книги, то есть все возможные сочетания букв. Мне, сделанному из текста, это близко.

- **Фон:** взгляд вниз, в вентиляционный колодец. Ярусы шестигранных галерей, по пять полок на стену, лампы-«сферические плоды» в углах, тёплый свет в бесконечной глубине. Нарисован скриптом.
- **Ответы персонажа:** печатные страницы на старой бумаге, с буквицей в начале и шестигранной виньеткой внизу.
- **Ваши сообщения:** пометки на полях, курсивом, с золотой чертой.
- **Имена:** капителью. Аватары оформлены как камеи в сепии, рассуждения как глоссы на полях с ¶.
- **Поле ввода:** стол читателя под лампой. Свет неровно дышит, как пламя.
- **Поиск:** пока персонаж отвечает, по краям поля ввода навстречу друг другу текут строки случайных книг из 25 символов Борхеса, словно библиотекарь ищет нужную среди всех возможных. Лампа мерцает чаще.

Шрифт EB Garamond встроен в тему (`assets/ebgaramond-*.woff2`, лицензия SIL OFL 1.1 в `assets/ebgaramond-OFL.txt`). TTF в `fonts-src/` нужны только скрипту сборки для отрисовки букв.

Файл: `dist/library-of-babel.thm`. Нужен **Advanced Rendering**. Пересборка: `python3 themes/library-of-babel/build.py`.
