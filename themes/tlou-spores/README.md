# TLOU // Spores

Тема для Tavo по The Last of Us Part I. Заражённый подвал: сырой бетон, рыжие колонии кордицепса, холодный луч фонарика, в котором висят споры. Надписей нет.

- Файл: `dist/tlou-spores.thm`. Нужен **Advanced Rendering**.
- Пересборка: `python3 themes/tlou-spores/build.py` (Pillow и numpy). CSS лежит в `style.css`.

Фишки:
- 🍄 **Споры:** медленно плывут по сообщениям персонажа, а из угла сообщения растёт кордицепс.
- ✨ **Светлячки:** два слоя медленно и плавно плывут над полем ввода навстречу друг другу («Look for the light»).
- 😷 **Противогаз:** поле ввода оформлено как стекло маски в резиновой оправе, внизу полоска фильтра. Пока персонаж генерирует, фильтр расходуется, а стекло запотевает в ритме дыхания.
- 👂 **Listen Mode:** во время генерации ваши сообщения и аватар становятся серыми и тусклыми, а сообщения, аватар и имя персонажа светятся белым силуэтом, как враги в режиме прислушивания.

Размеры сообщений не меняются ни в одном состоянии, все эффекты делаются цветом, свечением и фоном.
Генерация отслеживается через CSS `:has()`. В старых WebView Listen Mode и противогаз не включатся, остальное работает.
