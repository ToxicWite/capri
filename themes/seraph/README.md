# Seraph

Изящная ангельская тема для Tavo, тёмная и спокойная, для ролевых.

Первая версия называлась «Ophanim». В ней были кольца из десятков глаз, и это выглядело скорее жутко, чем ангельски. Глаз больше нет: вместо них свет, перья, звёзды и золото.

- **Фон** — чёрная пустота с мягким тёплым светом сверху. В нём золотой нимб с гравюрными лучами и сияющей четырёхлучевой звездой. Под нимбом широко раскрыты крылья из перьев-гравюры с лёгким свечением. По фону рассыпаны искры, внизу медленно опадают перья.
- **Ответы персонажа** — тёмный мрамор с мягкими прожилками и скользящим бликом. В углу рамки золотая звезда, от неё по кромкам расходятся тающие линии.
- **Ваши сообщения** — чёрный лист в двойной гравюрной рамке.
- **Имена** набраны капителью, перед ними золотая ✦. Аватары монохромные.
- **Поле ввода.** Над ним тонкая золотая черта со звездой.
- **Генерация.** Пока персонаж отвечает, над полем **опускаются белые перья**, а у его аватара загорается **золотой нимб**.
- **Шрифт** Cormorant Garamond / Cormorant SC (SIL OFL 1.1), лицензия лежит в `assets/`.

Файл: `dist/seraph.thm`. Нужен **Advanced Rendering**. Пересборка: `python3 themes/seraph/build.py`.
