# Not a Human

Тема для Tavo по мотивам хоррора «No, I'm Not a Human»: тёмная дверь, ядовитый бирюзовый, полутоновый растр и кадры-улики в светящихся рамках.

Две версии:
- `dist/not-a-human.thm`, «Not a Human // Visitor Check»: с английскими надписями.
- `dist/not-a-human-silent.thm`, «Not a Human // Silent»: те же эффекты, без надписей.

Нужен **Advanced Rendering**. Пересборка: `python3 themes/not-a-human/build.py`.
Общий CSS лежит в `style.css`, надписи в `labels.css`.

Фишки обеих версий:
- **Фонарик-осмотр:** пятно света медленно ползёт по сообщениям персонажа.
- **Дыхание:** пока идёт генерация, сообщения персонажа медленно «дышат».
- **CRT-телевизор:** поле ввода со сканлиниями, свечением и редким мерцанием; «стоп» мигает красной лампой эфира.
- **Досье:** все аватары перекрашены в постеризованный бирюзовый, персонажа время от времени «фотографируют со вспышкой».
- Ваши сообщения выглядят как светлые мятные фото из коллажа, ответы персонажа как тёмные кадры в рамке.

Только в Visitor Check:
- у каждого имени меняется вердикт `[HUMAN?] → [VISITOR?] → [???]`;
- у рассуждений подпись `// INSPECTING`;
- в углу экрана-поля `CH-03`, во время генерации `● ON AIR`.

Дыхание и ON AIR опираются на CSS `:has()`: в старых WebView они просто не включатся, остальное работает.
