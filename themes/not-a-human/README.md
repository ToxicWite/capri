# Not a Human

Тема для Tavo по мотивам хоррора «No, I'm Not a Human» (Trioskaz). Визуальный язык взят со скриншотов игры:

- **Ночь «через глазок».** Фон — вид с крыльца: дверной косяк, доски, тропинка, панельки, столб и бледная фигура вдали. Бирюзовый монохром, зерно и скруглённая тёмная виньетка, как в кадре игры.
- **Реплики** — голые чёрные плашки, как диалоги в игре: у гостя бирюзовый текст, ваши ответы на тёмной плашке «варианта ответа».
- **Аватары** — фотокарточки осмотра в светлой рамке: персонаж в ночной бирюзе, вы в тёплом «домашнем» тоне.
- **Вложения** в такой же светлой рамке, как вставка с руками при осмотре.

Две версии:
- `dist/not-a-human.thm` — «Not a Human // Visitor Check», с английскими надписями.
- `dist/not-a-human-silent.thm` — «Not a Human // Silent», без надписей.

Нужен **Advanced Rendering**. Пересборка: `python3 themes/not-a-human/build.py` (Pillow и numpy). Общий CSS лежит в `style.css`, надписи в `labels.css`.

Движение в обеих версиях:
- 🔦 По репликам гостя ползёт луч фонарика.
- 🫁 Пока идёт генерация, его реплики «дышат».
- ⚡ Над полем ввода ряд ромбиков энергии, как в игре. Во время генерации они тают один за другим.
- 📺 Поле ввода — синий экран старого CRT. Во время генерации по нему идут помехи.
- 📷 Аватар гостя время от времени снимают со вспышкой.

Только в Visitor Check:
- во время генерации по экрану бежит строка `STAY CALM · DO NOT LEAVE THE HOUSE DURING THE DAY · LOOK FOR THE SIGNS`;
- у рассуждений подпись `— examining the guest`.

Генерация отслеживается через CSS `:has()`. В старых WebView «генерационные» эффекты просто не включатся, остальное работает.
Ромбики стоят в отступе над полем ввода (`padding-top` у `.tavo-composer`). Если в Tavo они наедут на что-то, подвиньте `background-position`.
