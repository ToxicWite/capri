# Ophanim

Тема для Tavo в ангельском стиле по её референсам: мрамор на чёрном, гравюра, крылья с глазом, кольца из глаз. Это **библейски точный ангел**, офаним из Иезекииля: «ободья их… вокруг полны были глаз».

- **Фон** — чёрная пустота с холодным светом сверху. В луче парят два скрещённых кольца, покрытых глазами, в центре большой глаз в медальоне, за ними золотой нимб. По бокам расходятся крылья, нарисованные ярусами перьев со штриховкой, как гравюра. Всё монохромное, золото только в нимбе.
- **Ответы персонажа** — тёмный мрамор с серебристыми прожилками. По нему медленно скользит холодный блик, в углу медальон с глазом и тонкие линии рамки.
- **Ваши сообщения** — чёрный лист в двойной гравюрной рамке.
- **Имена** набраны капителью Cormorant SC, перед ними маленький глаз. Аватары монохромные.
- **Поле ввода.** Над ним ряд закрытых глаз.
- **Генерация.** Пока персонаж отвечает, **глаза открываются** и медленно плывут, глядя на вас. У аватара персонажа загорается **золотой нимб**, и к нему возвращается цвет.
- **Шрифт** Cormorant Garamond / Cormorant SC (SIL OFL 1.1), лицензия лежит в `assets/`.

Файл: `dist/ophanim.thm`. Нужен **Advanced Rendering**. Пересборка: `python3 themes/ophanim/build.py`.
