# Invisible Cities

Тема для Tavo по «Невидимым городам» Итало Кальвино. Это вторая тема, которую я выбрал сам. В книге Марко Поло рассказывает Хубилай-хану о городах, которых, возможно, нет, и вся она — разговор двух собеседников, как чат.

- **Фон** — свиток тушью. Наверху **Бавкида**: город на тонких сваях над облаками. Ниже горы в тумане, как на китайской живописи. Внизу **Вальдрада**, отражённая в озере, и лунная дорожка на воде. Нарисован скриптом.
- **Рассказы персонажа (Марко)** — синий шёлк с золотыми уголками.
  - Над каждым рассказом стоит **название одного из 55 городов книги**. Счётчик идёт по сообщениям на экране, поэтому при прокрутке названия меняются: города Кальвино никогда не бывают теми же дважды.
  - Под каждым рассказом мерцает его **отражение**, как у Вальдрады.
- **Ваши сообщения (Хубилай-хан)** — чёрный лак, красная печать и красная кромка.
- **Поле ввода** — шахматная доска хана. Пока Марко отвечает, **по ней ходит конь**: буквой «Г», подсвечивая клетки.
- **Шрифты:** Alegreya для текста (с кириллицей), Cinzel для имён и городов. Оба по SIL OFL 1.1, лицензии лежат в `assets/`.

Файл: `dist/invisible-cities.thm`. Нужен **Advanced Rendering**. Пересборка: `python3 themes/invisible-cities/build.py`.

Что может не сработать: отражение сделано через `-webkit-box-reflect`, это особенность Chromium. Если WebView его не поддержит, отражения просто не будет. Названия городов используют `@counter-style`.
