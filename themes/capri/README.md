# Capri // Project Capricorn

Тема для Tavo по мотивам Капри (Project Capricorn): красный звёздный глиттер, кислотно-зелёный, чёрные осколки, фиолетовый сдвинутый контур.

- Готовый файл: `dist/capri.thm`. В Tavo: More → Themes → Import theme.
- Для CSS-эффектов включите **Advanced Rendering**. Без него остаются базовые цвета, шрифты и фон.
- Пересборка: `python3 themes/capri/build.py` (нужен Pillow). CSS лежит в `style.css`, `theme.json` генерируется.

Фишки:
- глаз Капри перед каждым именем, он моргает;
- зубастая ухмылка в углу каждого ответа Капри;
- глитч-появление её сообщений и «сбой» зелёного аватара раз в 7 секунд;
- зазубренные аватары-осколки;
- заголовок рассуждений помечен `// CAPRICORN.SYS`;
- поле ввода загорается красным при фокусе, кнопка «стоп» пульсирует во время генерации;
- выделение текста кислотно-зелёное;
- в тексте: *действия* фиолетовые, «реплики» Капри зелёные;
- при `prefers-reduced-motion` анимации отключаются.

Все картинки нарисованы скриптом, кадров из аниме в теме нет, поэтому её можно публиковать в Tavo Hub.
