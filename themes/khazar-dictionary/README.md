# Dictionary of the Khazars

Тема чата для Tavo по роману Милорада Павича «Хазарский словарь». Идея Claude.

Словарь из трёх книг — Красной, Зелёной и Жёлтой: три версии одной истории, и ни одна не права до конца.

- **Фон** — ночной Каспий: на берегу силуэт хазарской крепости с одним горящим окном, низкая луна в дымке, лунная дорожка, а среди звёзд еле видны буквы — те, что забыла принцесса Атех.
- **Ответ персонажа — словарная статья.** Над текстом заглавное слово и книга (*Ateh · The Red Book*, *Khazar Polemic · The Green Book*…), цвет корешка слева и вкладка-указатель с буквой на правом краю (картинкой, чтобы не зависеть от разметки Tavo), как в старых словарях. Книга и статья выбираются по самому сообщению (число абзацев и курсив), так что соседние ответы обычно из разных книг.
- **Ваши сообщения** — заметки читателя на полях, курсивом.
- **Пока персонаж отвечает**, над полем ввода поднимаются и расплываются буквы: Атех забывает свой язык.
- По верхнему краю поля ввода — три тонкие закладки трёх книг; разделитель — три ромба тех же цветов.
- Книги различаются только цветом, без религиозных символов.

Шрифт Alegreya (SIL OFL 1.1, лицензия в `assets/alegreya-OFL.txt`). Нужен Advanced Rendering.

Сборка: `python themes/khazar-dictionary/build.py` → `dist/khazar-dictionary.thm`.
