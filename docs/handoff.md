## Как устроены темы Tavo (проверено на практике)
- `.thm` — ZIP: в корне `theme.json` (`"spec": "tavo_theme_v1"`, `name` ≤ 40 символов), картинки/шрифты в `assets/` без вложенных папок. В CSS ссылки вида `url("theme/assets/имя.png")`.
- Поля в архиве snake_case (`custom_css`, `user_bubble`, `background.charAvatar`), цвета — десятичное `0xAARRGGBB` (например `4280297528`). В CSS — обычные цвета.
- CSS работает только с **Advanced Rendering**. Публичные селекторы: `.tavo-bubble`, `.tavo-user-bubble`, `.tavo-character-bubble`, `.tavo-*-bubble-content`, `.tavo-message-content`, `.tavo-message-reasoning`, `.tavo-message-divider`, `.tavo-avatar`, `.tavo-user-avatar`, `.tavo-character-avatar`, `.tavo-speaker-name`, `.tavo-composer`, `.tavo-composer-shell`, `.tavo-composer-input`, `.tavo-composer-send/stop/add/voice-icon`, `.tavo-action-bar-button(-group)`.
- **Работает:** CSS-анимации, `:root:has(.tavo-composer-stop-icon)` для эффектов «пока персонаж отвечает», `::before/::after`, `::first-letter`, `@font-face` из assets, SVG-ассеты, многослойный `background-image`, `-webkit-box-reflect`, `:has()` по содержимому сообщения.
- **Нельзя:** менять размер пузырей (`transform: scale` и т.п. — длинные сообщения наезжают на соседние); CSS-счётчики между сообщениями (каждое изолировано, всегда 1).
- Рамки аватаров — `outline` с отрицательным `outline-offset`, не внешняя `box-shadow`.
- Декор внутри пузыря ограничивать по ширине (`min(90px, 50%)`): пузырь «•••» очень узкий.
- Покадровая смена картинок (`steps`) выглядит дёргано — лучше плавное движение `background-position`.
- Hub: обложка 1080×1920 (9:16). В карточке видно примерно 44–97% высоты, поэтому логотип и чат держать внизу, сверху — только фон.

## Порядок работы над темой
1. Уточнить у меня стиль/фишки, посмотреть референсы.
2. Нарисовать фон и ассеты скриптом, написать CSS.
3. Собрать `.thm`, проверить архив и посмотреть на макете чата.
4. Сделать обложки для Hub.
5. Прислать мне `.thm` — я ставлю на телефон и присылаю скриншоты, по ним правим.
