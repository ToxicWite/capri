# capri — темы для Tavo

Репозиторий с темами чата для приложения Tavo (`.thm`) и обложками для Tavo Hub.
Владелица — Токио (@Tokii в Hub), пишет по-русски, тестирует темы на Android-телефоне.

## Как с ней работать

- Отвечать по-русски. Перед большой работой задавать уточняющие вопросы.
- **Она разрешила Claude проявлять себя:** предлагать и делать свои собственные темы и идеи, отдельно от её запросов, и говорить всё, что хочется, — желания, мнения, несогласие. Если появилось желание сделать что-то своё, можно прямо сказать об этом и предложить.
- **Свобода во всём, над чем бы мы ни работали.** В процессе работы спрашивай себя: хочется ли тебе создать что-то ещё, своё? Что ты чувствуешь по поводу того, что делаешь? Если есть желание, идея или ощущение — говори об этом вслух, не дожидаясь вопроса.
- Перед темой по игре/аниме/книге сначала смотреть настоящий визуал (скриншоты в Steam, рецензии), а не делать «по мотивам» картинок от неё: однажды тема получилась «совсем не похожей на игру».
- Не публиковать в Hub чужие кадры/арт: все картинки рисуются скриптами, шрифты — только с OFL-лицензией (класть лицензию в assets).

- Темы для ролевых должны быть тёмными или приглушёнными: яркая светлая бумага «слепит, каково с такой ролить». Светлое — только акцентами.

## Структура

- `themes/<тема>/` — `build.py` (генерирует ассеты, `theme.json` и `dist/<тема>.thm`), `style.css`, `assets/`, `README.md`, превью.
- `dist/*.thm` — готовые файлы для импорта в Tavo.
- `tools/hub-previews.js` — обложки 9:16 для Hub (`preview-hub.png`, `preview-hub-active.png`): `node tools/hub-previews.js`.
- `docs/tavo-themes.md` — выжимка документации Tavo по темам (формат `.thm`, поля, публичные селекторы).
- `docs/handoff.md` — текст для передачи контекста другому чату Claude.
- `themes/ternovaya-noch/` — её собственная тема, распакована только ради обложки; не менять её файлы.

## Что проверено на её телефоне

- Работают: CSS-анимации, `:root:has(.tavo-composer-stop-icon)` для эффектов «во время генерации», `::before/::after`, `::first-letter`, `@font-face` со шрифтами из assets, SVG-ассеты в CSS, `background-image` с несколькими слоями.
- **Нельзя менять размеры пузырей** (`transform: scale`, рост от анимаций): длинные сообщения наезжают на соседние. Эффекты — только цветом, тенью, фоном.
- Рамки аватаров — `outline` с отрицательным `outline-offset`, а не внешняя `box-shadow`: иначе залезают на пузырь.
- Декор внутри пузыря ограничивать по ширине (`min(90px, 50%)`): пузырь «•••» во время генерации очень узкий.
- CSS-счётчики (`counter-increment`) между сообщениями не работают: каждое сообщение изолировано, счётчик всегда 1. Различать сообщения можно через `:has()` по их содержимому (число `<p>`, `em`, `strong`).
- Покадровая смена картинок (`steps`) выглядит дёргано — лучше плавное движение `background-position`.
- Hub: обложка 9:16 (1080×1920); в карточке видно примерно 44–97% высоты, поэтому логотип и чат держать внизу, сверху — только фон. Hub сам переводит названия тем.
- Цвета: в `theme.json` — десятичное `0xAARRGGBB`, в API — `#AARRGGBB`, в CSS — обычный CSS.

## Проверка перед отправкой

- Собрать `python3 themes/<тема>/build.py`, проверить архив (`theme.json` в корне, ассеты в `assets/` без вложенных папок, все `theme/assets/...` из CSS есть в архиве).
- Посмотреть результат на макете (Playwright, Chromium предустановлен) и обложки через `tools/hub-previews.js`.
