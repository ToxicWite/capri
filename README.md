# Capri · Norsk 🇳🇴

Личное приложение для изучения норвежского (букмол), уровень A1 → A2.
Тёмная «северная ночь» с северным сиянием, работает на телефоне как приложение и без интернета.

## Что внутри
- **Словарик**: около 350 слов в 15 темах (в том числе «Norsk sjel»: koselig, utepils, pålegg…), поиск, избранное, **свои слова**
- **Умное повторение**: слова возвращаются через 1 → 2 → 4 → 8 → 16 → 35 → 90 дней
- **Тренировка дня**: новые слова + повторение, ошибки повторяются в конце
- **Мини-игры**: Lynet (60 сек), En eller et? (род), Par (пары на скорость), Lytt (на слух), Skriv (написание с æ ø å), работа над ошибками
- **Затягивалки**: стрик 🔥, ледяной оберег 🧊 (спасает стрик), цель дня, 12 уровней от Turist до Allfader, 20 ачивок, комбо
- Озвучка норвежским голосом устройства, звуки, вибрация, резервная копия прогресса

## Как запустить
Локально: `python3 -m http.server` → открыть http://localhost:8000

На телефоне: включить GitHub Pages (Settings → Pages → Deploy from branch), открыть ссылку
и нажать «Поделиться → На экран „Домой“» (iPhone) или «Установить приложение» (Android).

Если не слышно озвучки — установи норвежский голос в настройках телефона
(iPhone: Универсальный доступ → Устный контент → Голоса → Norsk).

Прогресс хранится только на устройстве (localStorage). Чтобы перенести его, используй «Сохранить резервную копию» на вкладке Meg.
